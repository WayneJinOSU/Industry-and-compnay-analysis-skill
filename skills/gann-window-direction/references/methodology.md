# 总体方法

## 核心命题

江恩精确时间点不是方向信号，而是方向选择的观察时刻。方向需要由外部市场先验、前序路径、关键位交互、量价确认和波浪约束共同确定。

```text
时间窗口：何时值得观察
外部市场：盘前先验偏向哪里
前序路径：卖方/买方是否已经连续占优
关键空间位：方向分界在哪里
成交量与内部：是否有资金确认
波浪：当前行为处在何种结构阶段
大模型：在结构化证据上选择情景
```

## 决策优先级

1. 数据截止时间与未来函数审计；
2. 上游江恩、波浪结果是否合法；
3. 波浪硬约束；
4. 前序价格路径及其重复/恶化；
5. 外部市场与A股内部映射；
6. 关键位交互、反弹高低点和失败反抽；
7. 外部市场、成交量、板块和宽度确认；
8. 江恩时间/空间对合法情景排序；
9. 大模型输出结构偏向、窗口状态与行动偏向。

外盘和量价只能调整置信度与执行状态；没有结构失效证据时，不得抹除关键位破坏或失败反弹形成的结构偏向。

## 结构方向与窗口确认的分离

每个截点都可以独立重跑，但相邻截点的核心结构判断必须时间连续：没有明确结构失效时，短线反弹只能改变窗口确认度和执行状态，不能把偏空/偏多结构直接改写为中性。

必须分开记录：

```text
structural_bias   # 中高周期结构偏向
window_state      # 本次窗口是否已完成方向选择
execution_state   # 是否具备立即执行条件
```

“浪段身份待证”不等于“方向中性”；“窗口未决”不等于“结构无偏”。

## 先验与后验

盘前报告只输出先验和验证条件，不把叙事当作事实。开盘和盘中数据到达后，更新窗口状态；收盘后记录事实，不修改历史决策。

推荐使用以下语言：

- “盘前偏向……”；
- “若出现……则向上确认”；
- “若重复……则窗口向下选择”；
- “当前仍未决”；
- “该判断需要后续确认”。

避免使用：

- “时间点必涨”；
- “某个外盘涨幅必然映射A股”；
- “没有突破所以一定下跌”。
