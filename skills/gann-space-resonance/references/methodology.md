## 1. 机械定义

使用 high-low ZigZag 作为答案集。指数反向幅度达到5%确认转折；个股默认12%。转折价格取影线极值，突破/跌破判断使用收盘价。最后未确认的运行端点不进入命中率。

每个转折必须保留：

- `pivot_date`：极值实际发生日。
- `confirm_date`：反向幅度首次达到阈值、市场参与者能够知道该转折的日期。

任何目标日只能使用 `confirm_date < target_date` 的锚点。日线同一天同时满足高低反转时存在盘中顺序歧义，报告中列为边界；必要时按独立日期合并做敏感性分析。

## 2. 空间工具

### 分割位（主线）

对已确认波段 `P0 -> P1` 生成：

- `P1 - k/8 * (P1-P0)`，`k=1..7`。
- `1/3`、`2/3`。
- 三拐点结构生成1倍、1.5倍扩展位。

50%最高级；3/8、5/8、1/3、2/3次级。所有这些只算一个 `division` 来源。

### 角度线（辅助）

生成1x1、1x2、2x1。指数默认把前一波段点数除以日历天数解释为点/日；ATR60乘0.7和固定0.5点/日仅作预设对照。不同角度线仍只算一个 `angle` 来源。

### Square-of-9圆周位（定位）

公式：`level = (sqrt(anchor) + theta/180)^2`。主测90°步进。锚点必须在使用时已确认；历史展示可用样本内最深已确认低点，但不得回填到锚点确认前。

### 历史记忆

使用已确认历史高低点、百点/千点整数关口。它们属于一个 `memory` 来源。整数位密集会显著抬高价格覆盖率，不能用高命中率证明有效。

## 3. 共振与统计

两条以上不同 `source_family` 的价位相距不超过2%时合并为空间簇。中心取成员均值，同时保留成员最小值、最大值和来源清单。

空间基线在对数价格轴上计算全部候选带的并集覆盖率。用1000次均匀对数价格模拟交叉核验。主检验为单侧二项检验，预设参数族使用Bonferroni校正。

拐点命中回答“线是否靠近后来确认的高低点”。触碰事件回答“价格进入带后是否守住并产生有利运动”。两者必须分开：前者显著不代表后者可交易。

## 4. 已验证经验

上证指数2021-08-16至2026-08-14基准回归：

- 分割位±2.5%：31/43，72.1%；覆盖率35.1%；超额+37.0pp；校正p<0.001。
- 分割位±1.5%：25/43，58.1%；覆盖率28.8%；超额+29.3pp；校正p约0.001。
- 波段角度线±2.5%：超额约+15.8pp，但多重校正后不显著。
- 圆周图、历史记忆、全部工具和多源簇在扣除高覆盖率后没有稳定超额。
- 实际触碰后的5/10/20日反应没有任何工具在匹配基线和多重校正后显著。

因此，将分割位写为“有统计迹象、待扩样”；将角度线写为辅助；将圆周图与历史记忆写为定位工具；不得写“江恩共振整体有效”。

## 5. 时间周期处理

当前基准没有发现可直接升为主信号的显著时间周期：

- 大窗组合±2仅弱超额且不显著。
- 120日是较稳定的探索性候选；720日数值较高但集中于单一行情阶段。
- 180日、360日、季末、节气、财报截止节点及截止日前一个月均未显示稳定作用。

默认不把时间周期加入主信号。用户明确要求时，冻结候选锚点后并列运行四类时钟：

1. 5%因果拐点的预设自然日周期，主容差±2日，±3日只作敏感性；沿用本基准时，锚点必须严格早于目标日减60个自然日。
2. 5%因果拐点后的21、34、55、89、144个交易间隔。
3. 2.5%因果拐点后的5、8、13、21、34个交易间隔；只描述低级别节奏，不能越级确认父级浪。
4. 人工审定波浪段落时长的0.618、1、1.618倍，分别按自然日和交易日计算；脚本不得根据吻合日期反推浪型。

5%与2.5%、自然日与交易日时钟都以价格拐点为输入，属于同一`price_pivot_clock`因果来源。波浪等时属于`wave_duration`来源，但若段落或投影锚点因目标日期吻合才被选择，则不构成独立证据。`window_count`只描述窗口成员，不能作为置信度；报告另列`source_family_count`和保守的`independent_family_count`。

未来交易日必须优先使用交易所日历。缺失时可用工作日估算探索，但标记`estimated_weekday`并在正式判断前重跑。每个窗口分别记录极值候选、首次价格反转、宽度反转、指数确认、扩散/跨指数确认和周线确认，不能把它们合并为一个变盘日。

历史验证对自然日大周期、交易日大周期、低级别交易日和波浪等时分别计算：日期覆盖率、极值命中率、首次价格确认命中率、宽度/跨指数确认命中率、周线确认命中率及确认延迟。增加时钟或扩大容差会机械提高覆盖率，不得用总命中数增加证明预测能力；必须与同覆盖率随机/固定日历基线比较，逐周期校正，并进行滚动样本外检验。窗口结束后禁止更换锚点、计时单位或容差。

对外时间输出只列重要关键时间点（原始中心日期），不得列日期区间；容差与起止保留在审计账本。筛选与去重遵循 `multiclock-time.md`，单日展示不改变上述统计口径或证明预测精度。空间支撑压力继续用成员区间展示。

## 6. 输出解释

正文顺序固定为：

1. 一句话结论。
2. 当前价格与最近支撑/压力区。
3. 区内成员和独立来源。
4. 分割位、角度线、圆周图、历史记忆各自的历史超额。
5. 触碰后反应相对匹配基线。
6. 样本量、前视边界、多重检验和非投资建议。

圆周图负责呈现角度、价格螺旋与共振区；文字负责说明统计证据。不得让视觉密度代替统计结论。
