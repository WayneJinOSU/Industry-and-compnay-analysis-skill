# A股指数波浪计数

## 目的

保留艾略特波浪的硬约束，同时针对A股指数常见的政策跳变、涨跌停传导、T+1、行业轮动和权重分化，提升对复杂调整、二次探底和多级C浪的识别能力。市场特征只能改变候选结构的先验权重，不能修改波浪规则或替代价格确认。

## 四级账本

分析A股指数时按以下层级书写，禁止把不同级别的标签混用：

1. 月线：牛熊环境和更大级别趋势。
2. 周线：父级 `1-2-3-4-5` 账本。
3. 日线：父级2浪或4浪的 `A-B-C`、三角形或组合调整。
4. 日线以下或更细日线拐点：A段或C段内部的 `1-2-3-4-5`。

父级4浪可以是锯齿、平台、三角形或组合调整；“4浪”是位置，不是固定的三段或五段形态。父级4浪若以A-B-C表达，C段仍可能内部走五浪：

```text
父级4浪
├── A
├── B
└── C
    ├── C1
    ├── C2
    ├── C3
    ├── C4
    └── C5
```

不得把“父级4浪是A-B-C”和“C段内部是C1-C5”写成互斥观点。

## A股复杂调整先验

A股指数在调整阶段可能更容易出现重叠、急跌急拉、二次探底和板块错位，原因包括政策与流动性跳变、T+1与涨跌停导致的分段出清、行业快速轮动以及权重股和市场宽度不同步。因此在简单A-B-C与复杂结构都合规时，必须保留以下候选：

- C段尚未完成：候选低点只是C3，反弹可能是C4，随后仍有C5。
- C段已经完成：候选低点是C5，后续已经进入父级5浪。
- 平台、三角形或W-X-Y：重叠使普通C段推动浪不成立。

这只是候选排序规则。没有滚动样本外统计时，不得声称“A股五段调整一定比三段更多”。

## C3低点与C段终点判别

当出现“低点后反弹”时，不得立即把低点命名为父级4浪终点。至少同时给出以下两个账本：

### 候选一：C段已完成

- 列出完整C1-C5的日期、价格、幅度和持续时间。
- C2不得越过C1起点。
- 标准推动C浪中，C4不得进入C1价格区域；若发生重叠，必须改查收敛/扩散对角线或放弃五浪标签。
- C3不得成为C1、C3、C5中最短的一浪；C5未完成时只能写“待验证”。
- 低点之后需要周线反转和父级5浪的局部推动结构，不能只凭一次反弹确认。

### 候选二：低点只是C3

- 反弹标为C4候选，不得提前虚构C4终点。
- C4结束后预期C5再次测试低位，但C5可以创新低、双底或失败五浪；“C5必然二次探底且不破低点”不是理论规则。
- C5结束必须由低一级五浪完成、价格收回和周线确认共同支持。

如果数据粒度不足以列出C1-C5，写“C段内部五浪待证”，禁止把视觉印象写成已确认事实。

## A股确认层

波浪硬失效位优先于确认层。确认层只改变置信度：

- 趋势线：报告10周简单均线、周线EMA13和EMA34。站稳应以周线收盘为准，并检查下一周是否立即跌回；单日或盘中越线不确认浪级切换。
- 成交：比较最新周成交额与近13周中位数。缩量反弹更符合B浪/C4候选，放量突破提高父级推动浪置信度，但不能独立定浪。
- 宽度：检查上涨家数、站上中期均线比例和行业扩散。指数上涨而宽度恶化，保留C4/B浪计数。
- 龙头：市场锚、风格龙头和叙事龙头应同步改善。权重独涨不等于父级5浪确认。
- 跳空与涨跌停：政策或情绪导致的单周跳变不自动完成一个浪；等待后续周线保持或回补结果。

## 时间与历史类比

- 明确使用自然日、交易日还是周数，不得混算。
- 时间预测用窗口而非确定日期。每个活跃浪的终点必须同时给出中心日或中心交易日数、前后2至5个交易日容差、当前时间状态和价格确认触发器；更新时明确标记“已到窗待价确认/价格先到/时间到而价格未确认/窗口命中/延迟/失效”。
- 时间点到达本身不等于浪完成：只有价格结构、周线收盘和必要的量价/宽度条件在窗口内出现，才可写“时间与价格共同确认”。若窗口结束仍无价格触发，必须写“时间命中但浪级未确认”或“时间预测延迟”，不得移动中心日期来保留预测。
- 江恩、斐波那契持续时间和历史类比只能提示观察窗口，不能决定C3、C4或C5标签。
- 使用“类似2020年某指数”时，必须给出可比标的、起止日期、归一化方法和失效条件；肉眼相似只能列为探索性证据。

## A股二次探底决策树

对于“父级4浪已经结束”与“当前仍在C4、后面有C5”的分歧，固定输出：

1. C3/C5候选低点及其硬失效位。
2. C4候选反弹高点、C1重叠检验和父级B段高点。
3. C5的核心价格区、延伸区和时间窗。
4. 低点后需要重新站稳的10周均线/EMA区。
5. 能确认父级5浪的周线突破位。
6. 直接突破、普通二次探底、向下延伸三条分支。

主路径必须在事前写明中心日期/交易日数、日期窗口、价格带、周线确认和重判条件。事后只按这些条件判定时间命中、价格命中、延迟或失效，不得移动浪级或时间锚点来保留原预测。
