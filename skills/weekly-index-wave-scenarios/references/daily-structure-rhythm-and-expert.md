# 日线结构、节奏量价与专家观点蒸馏

## 目的

在父级浪型已经由月线/周线界定后，用日线回答当前子浪究竟是推动、调整、C3/C4/C5，还是已经完成C段。日线定浪不能只靠ZigZag极值、斐波那契比例或外部空间线；必须同时比较内部形态、运行节奏、成交与动能。江恩空间在结构形成后参与候选排序和目标校验，但不能推翻价格硬失效。

## 分层融合顺序

1. **价格硬结构**：父级浪级、拐点顺序、2浪/4浪重叠、3浪长度、A-B-C或W-X-Y的最低成立条件。
2. **日线内部形态**：候选段内部更像三段还是五段；推动段是否方向清楚、重叠少，调整段是否反复、重叠多。
3. **节奏与量价**：交易日数、单位时间位移、实体/影线、跳空、ATR、成交额、上涨/下跌日扩散、MACD/RSI只作动能描述。
4. **空间共振**：斐波那契、历史枢轴与江恩分割/角度/圆周/记忆区共同检查终点和下一目标。空间层可在两个都合规的计数之间调整排序，不能挽救违反硬规则的计数。
5. **市场确认**：宽度、龙头、行业扩散、流动性和事件改变置信度，不替代价格失效位。

这不是互相隔离的流水线。空间层与市场层若明显冲突，应回到日线重新检查拐点和浪级；任何改数都要写明“原计数、触发事实、修改原因”，不得悄悄移动锚点。

## 日线价格审计

遇到C3/C4/C5、二次探底或“调整结束/尚未结束”争议时，先生成一张不含江恩线和目标线的日线图，至少覆盖当前父级调整的起点。图上保留OHLC、MA5/10/20、成交额及一个动能面板；江恩图另页呈现。

为首选和备选各列一张拐点账本：日期、影线极值、收盘、交易日数、点数、相对前浪比例、状态。先回答以下问题：

- 候选推动段能否看出五个低一级摆动，还是只能看出三段？
- 候选调整段内部是否能拆为a-b-c；c/a是否出现等长、1.272或1.618附近，但不得用比例替代形态。
- 上升段与下降段谁更快、实体更大、重叠更少、成交更集中？
- 反弹创新高时，成交、宽度或动能是否同步；若不同步，是否更像B浪/C4。
- 大阴/大阳、缺口、长影线发生在结构末端还是中途；单根K线只能触发验证，不能单独完成定浪。
- 时间确认：为每个候选拐点记录中心交易日数/日期、容差窗口、窗口是否已到、价格触发是否已出现，以及“窗口命中/价格先到/时间到而价格未确认/延迟/失效”状态。

## 节奏与量价比较

对相邻主段使用同一口径，至少比较：

- 价格幅度、交易日数、每交易日平均位移；
- 平均/中位成交额及相对20日或相邻主段的变化；
- 阳线/阴线数量、实体占振幅、ATR变化；
- MA5/10/20的排列与收复/跌破；
- MACD柱、DIF/DEA和RSI仅用于识别动能扩张或背离。

典型但非硬规则的性格：推动段通常方向性更强、重叠更少、位移更快；调整段通常重叠更多、耗时更长、量能衰减。A股政策跳变和权重分化会制造例外，因此必须把反例写入报告。

## 没有分钟数据时

日线同一天或相邻两天出现高低点竞争时，不得虚构盘中顺序。采用以下标记：

- `极值锚点`：日线可见的绝对高低点；
- `结构工作锚点`：为了复现某套内部计数而选用的功能性终点；
- `顺序待证`：只有分钟数据才能确认的内部a-b-c或扩张平台顺序。

结构工作锚点可以用于情景推演，但必须同时报告采用绝对极值后的重叠检验和结论变化。不得因为某个锚点让江恩或斐波那契更漂亮就选择它。

## 专家观点蒸馏模式

当用户要复现“大佬/专家”的判断时，目标是提取决策算法，不是替专家背书，也不是先用教科书否定。

1. 保存观点时间、当时可见数据、原始浪级、拐点、目标和证伪位。
2. 用专家自己的锚点复现主计数，标出其隐含规则：结构终点、收盘/影线口径、允许的重叠、量价或情绪条件。
3. 独立建立最强备选计数，不读取江恩目标来选择浪型。
4. 将两套计数放入上述五层融合框架；指出哪些证据来自价格、节奏量价、时间确认、空间共振或市场确认。时间比例只能排序或形成观察窗，不能单独完成定浪。
5. 给出逐级证伪位，而不是只有“对/错”。后续按事前条件记录命中、延迟、截短或失效，不得事后移动浪级保留结论。

## 融合裁决

| 组合 | 裁决 |
|---|---|
| 价格结构、节奏量价、空间共振同向 | 可列为主计数；仍保留硬失效与最强反证 |
| 价格结构强，空间不共振 | 浪型可保留，降低目标区精度，不因缺少江恩线否定结构 |
| 空间共振强，价格结构弱或违规 | 只能称观察区，不得据此命名C4/C5或反转 |
| 两套计数都满足硬规则 | 用内部三/五浪性格、节奏量价先排序，江恩空间再作次级区分 |
| 日线顺序无法裁决 | 明示工作锚点与极值锚点的两套结果，等待价格触发，不伪造确定性 |

最终必须用一段话回答：为什么首选结构在日线“长得像”该浪、为什么节奏量价支持或反对、江恩共振增加了什么信息、最强反证是什么。
