# 中文报告的阅读层

用于中文盘前、盘中、盘后和历史回放报告。目标是让交易结论可以直接读懂，
同时保持 JSON、门禁和评分使用稳定的机器字段。

## 强制语言规则

1. 所有面向用户的正文、标题、表格标签、解释、警告、结论和最终回复必须全部使用中文。
2. 禁止在叙述性文字中使用英文单词或英文缩写。市场名称、指标名称、方向、执行状态和判断结论必须翻译为中文。
3. 报告信息表、决策卡、执行覆盖、证据信息量和动作理由中，字段名与状态值必须同时翻译成中文。不得直接把 `prediction_type : backfill`、`execution_state : reduce_only` 之类的机器字段块作为阅读层。
4. 机器枚举仅保留在结构化数据、门禁、评分记录、文件路径、公式变量和证券代码中。结构化记录里的英文标识可以存在，但正文必须另有中文标签和中文值，不能用英文标识替代中文结论。
5. 下列常用表述必须使用中文：
   - “纳斯达克综合指数”“标准普尔五百指数”“费城半导体指数”；
   - “韩国综合指数”“日经二百二十五指数”“台湾加权指数”“恒生指数”；
   - “平均真实波幅”“移动平均线”“成交额”“上涨占比”；
   - “偏多”“偏空”“中性”“等待确认”“只减不加”“恢复进攻”。
6. 所有数量型数据必须使用阿拉伯数字和常规单位。价格、百分比、日期、时间、周期、金额、倍数、得分、样本数和版本号不得改用中文数字。

## 数字格式

中文只负责说明，数字负责表达数量。报告正文、表格、路径预测、目标和失效条件均
遵守以下格式：

| 错误写法 | 正确写法 |
|---|---|
| 三千九百五十八点零三 | 3958.03 |
| 百分之四点二九 | 4.29% |
| 九月二十二日 | 9月22日 |
| 二零二六年九月二十二日 | 2026年9月22日 |
| 十三周、三十四周 | 13周、34周 |
| 零点一八八倍 | 0.188倍 |
| 二万六千二百三十亿元 | 26230亿元 |
| 五日、三日 | 5日、3日 |
| 第三版 | 第3版 |

“第四浪”“丙二反弹”等已经固定为浪级或结构语义的名称可保留中文序数词；一旦
用于点位、涨跌幅、日期、周期、金额或样本统计，就必须使用阿拉伯数字。
“下一交易日”“下一次复查”等导航或语法表达不是数量数据，不得改写为
“下1交易日”“下1次复查”。

## 基本表达

1. 正文、标题和情景表必须全部使用中文。
2. 四情景的标准中文名固定为：

   | 机器名 | 中文主名 |
   |---|---|
   | `trend_continuation` | 趋势延续 |
   | `key_level_test` | 关键位区间测试 |
   | `breakdown_or_breakout` | 关键位突破/破位 |
   | `tail_extreme` | 尾部极值 |

3. 可在标准中文名后加括号说明路径性格，但不得用括号短语替代标准名：

   - 趋势延续（向下确认）
   - 关键位区间测试（基准：低开下探、日内修复）
   - 关键位突破/破位（向上确认）
   - 尾部极值（极端下破）

4. `prediction_type`、`structural_bias`、`direction`、情景 `name` 和
   `direction` 等机器枚举只能保留在结构化代码块、结构化数据、门禁与评分文件中，不得出现在叙述性正文。
5. “偏空/偏多/中性”是事件日收盘方向，不等同于中周期结构偏向。报告必须把
   两者分开表达。
6. “低开、反抽、测试、站上”是可观察的盘中路径；只有“收盘位于某区间”才是
   收盘情景归类条件。两者不得混写。

## 报告信息表

报告开头的元数据固定使用下面形式。日期、时间、版本号和数值保持数字，不回退为
中文数字；状态值和字段名必须中文化。

```markdown
| 报告项目 | 内容 |
|---|---|
| 预测类型 | 历史回放 |
| 规则版本 | 2026-10-25.6 |
| 决策阶段 | 盘前 |
| 预判截点 | 2026-09-22 09:00:00+08:00 |
| 特征截点 | 2026-09-22 09:00:00+08:00 |
| 目标日期 | 2026-09-22 |
| 门禁状态 | 带警告通过 |
```

## 决策卡

决策卡固定使用中文项目名和中文判断值：

```markdown
| 决策项目 | 决策内容 |
|---|---|
| 结构偏向 | 偏空 |
| 窗口状态 | 未决 |
| 事件日方向 | 中性 |
| 执行状态 | 只减不加 |
| 操作偏向 | 只减不加 |
| 是否弃权 | 否 |
| 置信度 | 0.55 |
| 决策区间 | 3958.03-3992.55 |
| 失效条件 | 收盘接受3992.55上方或跌破3916.49 |
| 下一确认 | 向下3916.49；向上3992.55 |
```

## 执行覆盖表

盘前执行覆盖固定使用中文值，不再展示机器枚举：

```markdown
| 执行项目 | 当前判断 |
|---|---|
| 决策模式 | 盘前设定 |
| 盘前设定状态 | 风险区亢奋 |
| 盘前检查得分 | 5/6 |
| 缺口状态 | 不适用 |
| 压力状态 | 尚未测试 |
| 参与度状态 | 未知 |
| 风险状态 | 提前防守 |
| 执行偏向 | 只减不加 |
| 防守触发 | 压力测试失败，或宽度与领涨确认仍未完成 |
| 恢复进攻触发 | 放量接受压力带防线且参与度确认 |
| 覆盖失效 | 快照晚于判断截点、时点不可验证或关键字段缺失 |
```

常见报告状态如下：

| 判断类别 | 中文显示 |
|---|---|
| 预测类型 | 前瞻预测、历史回放 |
| 结构偏向与事件日方向 | 偏多、偏空、中性 |
| 窗口状态 | 未决、向上确认、向下确认 |
| 执行状态与执行偏向 | 观察、等待确认、只减不加、弃权 |
| 决策模式 | 盘前设定、盘前设定与快照合并 |
| 盘前设定状态 | 风险区亢奋、条件观察、正常、未知 |
| 缺口状态 | 预期缺口、缺口确认、缺口回补、不适用 |
| 压力状态 | 尚未测试、已接受、已拒绝、待判定、不适用 |
| 参与度状态 | 确认、背离、未知 |
| 风险状态 | 正常、观察、提前防守、防守、进攻 |

门禁按字段分别规范化上述中文值。不得使用一张全局同义词表，因为“观察”在不同
字段中分别表示执行观察和风险观察，“停止操作”只属于操作偏向，不等于执行弃权。

## 情景总表

正文只放一张四行情景表，不再为每个分支重复写相同小节，但每个情景必须
保留完整路径预测：**开盘假设 → 首次测试 → 确认或失败 → 后续演化 → 收盘
区域 → 目标与失效**。不得把完整路径压缩成“下探后收回”或“反抽失败”一句。
路径是事前假设，不是收盘归类条件；收盘判定仍只由最终收盘位置决定。

```markdown
| 情景 | 权重 | 方向 | 完整路径预测 | 收盘判定 | 目标 | 失效 |
|---|---:|---|---|---|---|---|
| 关键位区间测试（基准：日内修复） | 40% | 中性 | 低开→测试 3640→收回并守住 3640→午后横盘修复 | 收盘位于 `[3640, 3680)` | 3660、3680 | 收盘离开该区间 |
| 趋势延续（向下确认） | 30% | 偏空 | 平开或低开→反抽 3640 失败→再破 3620→尾盘维持弱势 | 收盘位于 `[3600, 3640)` | 3584、3560 | 收盘回到 3640 上方 |
| 关键位突破/破位（向上确认） | 25% | 偏多 | 平开或低开→3640 获承接→放量突破 3680→回踩不破 | 收盘位于 `[3680, 10000]` | 3700、3720 | 收盘收回 3680 下方 |
| 尾部极值（极端下破） | 5% | 偏空 | 显著低开→3640 无承接→3600 快速失守→反抽无力 | 收盘位于 `[0, 3600)` | 3560、3540 | 收盘回到 3600 上方 |
```

四情景权重必须合计 100%，区间连续且不重叠。表下只补一句方向裁决，
例如“最高权重为关键位区间测试，因此事件日方向为中性；结构偏空仅约束
风险暴露”。若最高分支只微弱领先，必须同时写明“低确信、对权重扰动
敏感”，不得把分支权重差包装成胜率优势。路径可另在复盘时按实际开盘、
首次测试、确认和收盘逐步核对，不得用收盘分箱命中冒充整条路径命中。

## 写作边界

## 操作建议的唯一合格写法

任何操作建议都必须同时包含以下六部分：

1. **建议动作**：观察、等待确认、只减不加、确认后恢复进攻或停止操作。
2. **现在为何建议**：至少两条来自价格、时间窗口、压力距离、量能、宽度、领涨或外盘的独立理由。
3. **最强反方证据**：至少一条说明判断可能错误、或支持相反方向的事实。
4. **动作维持条件**：出现哪些价格、量能、宽度和参与度证据时，当前动作继续有效。
5. **动作解除条件**：出现哪些证据时会推翻并解除当前动作；不得把支持当前动作延续的证据写进解除条件。
6. **适用期限与复查点**：该建议适用于目标交易日、盘中更新还是下一交易日，以及何时复查。

不得只写“只减不加”“观察”“不追高”而不解释原因。报告必须设置“操作建议理由”小节，并逐条列出上述内容。

- 不把“基准”自动解释成看多。基准可以是中性区间测试。
- 不把“向上确认”写成“趋势反转确认”；反弹性质和结构切换是两层判断。
- 不因某档位未被跌破就增加同方向权重；档位只定义观察和收盘分界。
- 不把不同的容差、不同市场的时点或不同级别的确认合并成同一天。
- 每个成对方向都应给出独立的触发、目标和失效，不只给一句“看涨/看跌”。
