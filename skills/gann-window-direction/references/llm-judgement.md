# 大模型综合研判契约

## 定位

代码负责点时数据、状态事实、统一平均真实波幅、当前关键位、价格锚、无权重
收盘结算轴、执行风险事实和门禁。大模型独立负责中期结构、窗口状态、次日条件式
路径、风险状态和最终执行裁量；代码不生成操作动作或操作理由。

这里使用的是**多证据综合裁量**，不是经过校准的统计概率，也不是虚构的人类
实盘直觉。大模型只能综合当前可见证据，必须同时给出反证和失效条件。

## 输入

大模型必须读取完整输入包，至少包括：

- 江恩时间点与空间共振；
- 波浪父级、当前浪候选和结构失效位；
- 多日价格路径、成交额和宽度；
- 可可靠取得的两融、领涨和外围证据；
- 当前关键位登记及破位／收复记忆；
- 当前 `level_context` 价格锚与收盘结算轴；
- 脚本生成的执行风险事实与数据缺口。

缺少的证据保持缺口状态，不得编造。所有输入必须满足点时截点约束。

## 输出边界

大模型输出：

```text
structural_bias
structure_reason / structure_opposition / structure_invalidation
window_state
next_day_path
baseline_path_invalidation
execution_state / execution_action / risk_state
supporting_evidence / opposing_evidence
action_maintenance / action_invalidation
evidence_refs / horizon / next_review
```

禁止输出：

```text
任何情景权重或百分比分配
数值置信度、权重领先幅度、低确信或正常确信
由最高权重决定的顶层事件日方向
```

`weekly_regime` 等代码状态只是证据，不能直接代替 `structural_bias`。中期结构
应保持时间连续性；没有新增结构证据或明确失效条件，不得因一日反弹翻转。

## 次日路径

次日不是单点涨跌预测，而是：

```text
基准判断
→ 开盘点位或区间及观察锚
→ 盘中波动上下沿与至少2个有序观察节点
→ 基准收盘区域、位置和强弱性质
→ 向上切换条件与切换后收盘区
→ 向下切换条件与切换后收盘区
→ 独立尾部风险路径
```

点位必须来自当前价格锚。区间用于观察和切换，不表示保证到达。趋势与次日
路径冲突时，填写 `structure_path_divergence`，说明是时间尺度差异、短期修复
还是已经发生的结构失效。

## 理由完整性

- 至少2条结构依据和1条结构反证；
- 至少1条结构失效条件和1条基准路径失效条件；
- 至少2条执行支持理由和1条最强反方证据；
- 至少1条动作维持条件和1条动作解除条件；
- 至少1条可解析证据路径引用；
- 明确适用期限和下一次复查时点。

## 代码校验

代码只校验：

- 点时字段、允许状态与证据引用；
- 禁止使用权重、置信度和顶层方向；
- 开盘、盘中、收盘3段是否完整；
- 点位是否属于当前锚点、区间是否合法；
- 收盘位置是否与收盘区、支撑和压力的几何关系一致；
- 盘中节点、切换条件和尾部风险是否完整；
- 结构与路径冲突时是否说明分歧；
- forecast 是否原样复制研判；
- 执行理由与动作条件是否完整。

代码不替大模型重新决定结构、次日基准、风险状态或执行动作。
