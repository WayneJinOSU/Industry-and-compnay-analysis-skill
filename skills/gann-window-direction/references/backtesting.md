# 回测与未来函数审计

## 预测单位

以精确交易日为事件单位，分别评估：

```text
event_day_direction
forward_3d_direction
forward_5d_direction
window_direction_selection
```

不要把邻近日期合并成模糊命中窗口，除非另行定义并单独报告。

## 必须比较的模型层次

1. 江恩时间/空间基线；
2. 基线 + 量价；
3. 基线 + 前序路径记忆；
4. 基线 + 外部市场映射；
5. 完整规则模型；
6. 完整结构化输入 + 大模型判断。

重点做消融：

```text
路径记忆是否增加方向区分度
外部市场是否增加盘前判断增量
路径记忆与外部市场是否有交互增量
大模型是否超过固定规则和简单统计模型
```

## 对照组

至少使用：

- 相似趋势状态但非江恩窗口日；
- 相似波动率和成交量状态的普通交易日；
- 相同空间位置但无路径重复的交易日；
- 相同路径但无外部共振的交易日。

## 标签注意事项

“窗口向下选择”应提前定义，例如：

- 关键支撑收盘跌破并在后续规定交易日内不能收复；或
- 关键压力拒绝后，前一支撑被有效击穿；或
- 目标窗口内的方向收益超过预设的波动标准。

规则一旦确定，不得根据结果临时修改。

## 未来函数审计

保存：

```text
forecast_cutoff
feature_cutoff
upstream_result_version
external_data_available_at
prompt_version
model_version
```

盘前样本不得使用目标日的收盘、全天成交量、盘后新闻或事后确认的波浪拐点。盘中更新必须单独记录，不得覆盖盘前原始判断。

## 结果报告

至少报告：

```text
样本数
事件日准确率
多空分别的精确率/召回率
中性过滤后的准确率
基准超额
T+3/T+5平均收益
最大有利/不利波动
弃权率
置信度分层表现
```

高命中但没有超过匹配基线时，不得宣称具有交易增量。
