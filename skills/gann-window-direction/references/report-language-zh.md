# 中文报告的阅读层

## 强制语言与数字规则

1. 用户可见正文、标题、表格、解释、警告和结论全部使用中文。
2. 英文机器标识只保留在结构化数据、门禁、路径结算和文件路径中。
3. 点位、百分比、日期、周期、金额、倍数、样本数和版本号使用阿拉伯数字。
4. 不展示情景权重、数值置信度、权重领先幅度、低确信或正常确信。
5. 不再设置“事件日方向”总字段。中期结构、窗口状态、次日路径和执行分别表达。

## 决策卡

```markdown
| 决策项目 | 决策内容 |
|---|---|
| 结构偏向 | 看空 |
| 窗口状态 | 未决 |
| 次日基准 | 区间内偏弱，优先观察下沿测试 |
| 开盘点位 | 3550.00-3600.00 |
| 盘中波动点位 | 3500.00-3650.00 |
| 收盘点位 | 3550.00-3600.00 |
| 收盘性质 | 偏弱 |
| 执行状态 | 只减不加 |
| 操作偏向 | 只减不加 |
| 是否弃权 | 否 |
| 决策区间 | 3550.00-3650.00 |
| 结构失效条件 | 重新接受指定结构压力 |
| 基准路径失效 | 开盘与盘中均接受压力上方 |
| 下一确认 | 向下3550.00；向上3650.00 |
```

报告中的3个数值区间必须与 forecast 完全一致。收盘性质使用“偏强”“偏弱”
或“平衡”。

## 核心判断

固定说明：

```text
中期结构为何成立
最强结构反证
什么会推翻中期结构
窗口为何已确认或未确认
次日基准与中期结构是否分歧
```

“窗口未决”不等于“结构中性”。“次日修复”不等于“中期反转”。没有新增结构
证据时，不得为了迎合单日路径而改写中期结构。

## 次日路径表

正文主表只展示基准与切换，不展示权重：

| 路径环节 | 点位与观察内容 |
|---|---|
| 开盘 | 开盘区、前收关系、核心观察锚与强弱性质 |
| 盘中 | 波动上下沿、首次测试、接受或拒绝、后续演化 |
| 收盘 | 基准收盘区、区间位置和强弱性质 |
| 向上切换 | 触发位、确认条件、切换后的收盘区和失效 |
| 向下切换 | 触发位、确认条件、切换后的收盘区和失效 |
| 尾部风险 | 极端触发、风险目标和失效；不预设必然发生 |

路径是事前假设，不是保证到达。点位必须来自当前登记锚，不得为了填满模板
编造数值。

## 收盘性质

收盘位置与区间几何同时表达：

- 中枢平衡；
- 上沿偏强；
- 下沿偏弱；
- 支撑下方弱势；
- 压力上方强势。

宽区间下沿只能写“宽区间下沿偏弱”，不能写成高质量平衡震荡。收盘分箱只
用于结算，不能取代路径性质。

## 审计附录的收盘结算轴

四类标准中文名保留为：

```text
向下延续
区间震荡
向上突破
尾部极值（向下）
```

审计表只有“类别、收盘条件、区间”，没有权重列，也不从类别生成总方向。
路径与收盘结算分开评价。

## 执行覆盖与操作建议

执行覆盖保留中文状态、风险触发和覆盖失效。任何操作建议必须同时包含：

1. 建议动作；
2. 至少2条当前理由；
3. 最强反方证据；
4. 动作维持条件；
5. 动作解除条件；
6. 适用期限与复查点。

结构失效、基准路径失效和动作解除不得混为同一字段。

## 复盘表达

分别记录实际开盘、盘中最高最低和收盘。只有日线时，不得推断盘中节点先后。
宽区间边缘覆盖标记为“脆弱覆盖”，不作为高质量震荡命中。误判归因区分数据
缺口、分类口径、综合裁量和规则缺口。
