# 全浪段证据—判断转换与预判断

## 目的与范围

适用于所有活跃浪段：推动浪1–5、调整浪A/B/C、三角形A–E、组合调整W/X/Y，以及子浪结束、下一浪启动和父级浪级切换。不是为C浪另设一套方法，而是让每次判断都回答：**新增什么证据，原判断保持、增强、降级、失效，还是应改用哪个备选？**

本文件是工作判断协议，不是新增艾略特硬规则或已验证预测优势。各浪的内部形态与失效边界仍遵循现有[父级计数](multi-degree-counting.md)、[调整类型](correction-patterns.md)与[日线审计](daily-structure-rhythm-and-expert.md)。上升与下降方向镜像处理，但不同浪/调整类型不能共用同一硬失效规则。

覆盖所有浪类型不等于每次枚举所有浪。只对**当前活跃主计数、最强合规备选与下一关键切换**建立有用的证据表；不要为填模板发明端点或穷举远期分支。

## 1. 每次判断先固定四件事

1. **判断对象**：父级、浪级、浪段、结构类型和当前阶段（启动/延续/结束/浪级切换）。例如“父4结束→父5启动”与“父4内部C3结束→C4启动”是不同命题。
2. **原判断**：主计数、最强备选、当时已知锚点及其机械/结构确认状态，不只保存最终标签。
3. **截点和口径**：决策时间、数据可得时间、价格极值/收盘、周期、既定机械阈值及关键位来源。若无法认证历史发布时点，披露可得性限制，不宣称完整PIT认证。
4. **已有事实和未来条件**：截至截点已经出现的事实放 `observed`；尚未出现的反抽、续涨/续跌、周线确认放 `conditional`，不能混在同一事实叙述里。

同一根日线不能支持未经核验的分钟顺序；未完成周线不能当成已完成周线。极值发生时间、机械确认时间、首次结构判断时间分开，后续更新不回填原截点。

## 2. 通用证据层与允许的判断

| 新增证据 | 我会采用的结论 | 对浪段计数的影响 | 仍不能确认什么 |
|---|---|---|---|
| 仅触发既定机械反转阈值 | 局部顶部/底部获得机械确认，建立转折候选 | 上一浪可能结束、下一浪可能启动，列候选 | 整个浪已结束、精确浪级或下一浪身份 |
| 关键位按声明口径被接受突破/跌破，且已观察到跟随或回测失败 | 对应方向延续成为主情景，原反向修复预期降级 | 增强与方向相容的候选；结构不足时仍待证 | 价格破位自动等于某一浪启动 |
| 上一级关系可解释、前段完成有依据、当前内部形态合规，并得到相关延续/转折证据 | 将相应启动/延续/结束/浪级切换列为主计数 | 记录从候选到主计数的提升及最强备选 | 未观察到的子浪终点或未来完整结构 |
| 反向收复关键位、跟随失败或结构证据与原预期冲突，但未触犯硬规则 | 降低原主情景优先级，重排候选 | 可软降级；必要时切换最强备选 | 原计数必然硬失效 |
| 触犯该类型、该浪级已声明的硬边界 | 原指定计数失效，改审备选 | 保留原锚点及违规事实，明确重数原因 | 所有更大级别结构或全部长期趋势均失效 |

这些是不同维度，不是固定评分阶梯。结构证据可先于某条空间线到位；清晰趋势也可在精确浪段未决时先改变。**不必等整个目标浪走完才列启动候选，也不能把机械拐点当成结构完成证明。**

- 价格区间 `[L,U]` 的完整下破/上破分别按预定口径检验低于L/高于U；盘中触及或进入带内不等于收盘接受。突破/跌破的跟随、回测、ATR口径须事前声明。
- 机械反转参数、锚点与波动基准按当时已知数据计算；极值更新时保存旧版本和修改原因，不事后改变阈值迎合标签。
- 辅助量价、宽度、跨指数、领导股、时间/空间共振只作确认与排序，不能修复硬规则违规。缺失降低把握，不抹去清楚的价格事实；成交额代理不冒充两市总量。
- 硬规则违规先于软证据裁决；波浪硬边界按既定极值/精度口径审计，不能用“未收盘”或价格状态 `pending` 豁免。

## 3. 各浪把通用规则落实到什么证据

下表是结构检查方向，**不是每浪必须满足固定价格序列的自动标签器**。报告需用本次已知账本落实端点、价位和仍未解决的子浪；未来结构不得提前填写为完成。

| 判断对象 | 可以先建立候选的证据 | 提升主计数时重点审计 | 必须保留的反方/边界 |
|---|---|---|---|
| 1浪启动/结束 | 原趋势反转；新方向首段或其末端转折候选 | 上一级原段完成依据；首段内部推动或合规领先对角线；后续修正的关系 | 新方向上涨/下跌也可能只是原调整内部的一段；单次反弹不是新周期1浪 |
| 2浪启动/结束 | 1浪末端反转；修正段末端收回/续涨（下行推动镜像） | 1浪身份及终点；2浪调整类型、低一级完成依据；新方向初始结构 | 2浪可复杂化，不必是简单ABC；触犯1浪起点约束使原推动计数失效 |
| 3浪启动/延续/结束 | 2浪末端反转；越过1浪终点或动能扩张增强候选 | 2浪完成有依据；新推动内部结构与父级1–2关系；末端是否仍有子浪延伸 | 突破1浪终点本身不充分；在5浪未完成时不能宣称最终“3浪非最短”审计已通过 |
| 4浪启动/结束 | 3浪末端转折；横向/反向修正；修正后的新推动候选 | 3浪终点及低一级结构；4浪具体类型与完成证据；向5浪切换的初始结构 | 标准推动的1/4重叠边界；若采用对角线须有独立依据，不能为规避重叠改名 |
| 5浪启动/结束 | 4浪末端转折；末段推动或末端反转候选 | 4浪完成依据；5浪内部推动/末端对角线；父级1–5整体完成与反向初始结构 | 5浪可截短，不把必须超越3浪终点设成通用硬门槛；背离、碰目标不等于结束 |
| A浪启动/结束 | 前一主段转折；第一反向段或其末端反转 | 被调整的父级段是否完成；候选调整类型下A应有的内部形态 | A不一概要求五浪：锯齿与平台不同；也可能只是原推动中的2/4浪 |
| B浪启动/结束 | A末端反转；反弹/回撤段及其转折 | A身份与完成依据；B内部调整结构及当前类型约束 | B可复杂化；平台B可越过A起点，不能把“B不得创新极值”设为通用规则 |
| C浪启动/延续/结束 | B末端反转；下一方向段及后续转折 | B完成有依据；锯齿/平台C的合规内部结构；区分局部与父级完成 | B内部回调与C子浪延伸；三角形C不能套用推动式C1–C5判据；细则见[C专项](c-wave-launch-prejudgement.md) |
| 三角形A–E / 组合W–X–Y | 当前修正子段转折、边界交互或新连接段候选 | 各调整子段、顺序、相应类型边界和上一级位置；完成后是否有真正脱离 | 不把可见三/五个摆动自动命名ABC或推动；未完成E/Y不发明终点 |
| 子浪结束→父级切换 | 局部端点反转、收复/失守父级结构位 | 低一级完整性、父级硬约束和已完成父级周期确认 | 子浪顶底不自动等于父级顶底；先保留父级仍在延伸/调整的备选 |

浪身份与趋势可以分别裁决。例如某次“更高高点—更高低点”支持上行延续，但仍可能是B而不是3；下行结构可支持防守但仍可能是2/4而不是A/C。

## 4. 报告必须给出“新增证据 → 我会采用的结论”表

每份当前浪段判断都要为活跃关键分支输出证据—结论表，而不是只报“当前为X浪、置信度Y”。报告至少覆盖：

- 哪条证据只足以建立候选；
- 哪条证据会让趋势/延续主情景改变；
- 哪组价格与结构证据足以提升相应浪段主计数；
- 哪条反证软降级、哪条硬违规使原计数失效。

不同命题可以共用一条证据，也可以合并表行；不要用固定行数机械填空。每行直接写清：

| 新增证据/触发条件 | 截点状态 | 我会采用的结论 | 原计数→新状态/备选 | 仍未解决什么 |
|---|---|---|---|---|
| {有来源的具体价格、口径、结构条件及AND/OR关系} | {已发生/待验证/数据不足} | {趋势判断+浪段判断，勿混为一件事} | {保持/增强/降级/失效/切换；说明哪个浪级} | {子浪、父级、周期或备选歧义} |

阈值、端点和目标取自当时已知数据/账本，不能把本次个案的指数、日期、点位或参数写成永久规则。有数据时必须落到具体价位与可观察条件；未知则注明缺口，不以“站稳后确认”之类无口径话术替代。

预判断表写“若出现则采用”；更新表写“本次新增事实→实际改判”。不能只罗列证据却不裁决是否改变判断，也不能为了符合预期强行改判。没有增量证据时明确保持原判断。

## 5. 补充记录与更新

可附 `wave_transition_assessment`；既有机器接口不兼容扩展时另存同名JSON，不改变原协议枚举或覆盖上游结果。建议字段如下：

```json
{
  "decision_cutoff": null,
  "upstream_wave_asof": null,
  "current_count": null,
  "strongest_alternative": null,
  "pivot_assessment": null,
  "trend_assessment": null,
  "transitions": [
    {
      "wave_degree": null,
      "pattern_type": null,
      "from_wave": null,
      "to_wave": null,
      "phase": "start|continuation|completion|degree_transition",
      "count_status": "unresolved|candidate|preferred_count|invalidated",
      "anchors": [],
      "observed_evidence": [],
      "decision_rows": [],
      "soft_downgrade": [],
      "hard_invalidation": [],
      "unresolved_structure": []
    }
  ],
  "assessment_history": []
}
```

`decision_rows` 每条记录触发条件/组合逻辑、已发生或条件状态、来源与可得时间、采用的趋势/计数结论、原状态→新状态及备选。未知留null；示例中的枚举是可选值说明，不是多个状态的实际取值。锚点附极值时间、确认状态和首次可得时间。

记录原判断与本次新增事实、首次升级/降级时间，不静默改锚、不回写旧盘前结论。置信度如有变化说明证据原因，不强制生成新分数，也不把未校准分数当概率。时间/空间只排序，浪段或价格改变不能伪造正式江恩窗口信号。

C专项兼容字段 `c_wave_assessment` 可以保留，但通用评估以 `wave_transition_assessment` 为准；非C浪不填进C字段，上下游一致内容不得互相矛盾。
