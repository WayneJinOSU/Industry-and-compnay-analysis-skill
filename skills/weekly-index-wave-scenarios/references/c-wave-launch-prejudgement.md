# C浪启动专项：通用证据—判断机制的一个实例

先读[全浪段证据—判断转换](wave-evidence-transition.md)。截点、拐点/趋势/浪级分层、条件与事实、软/硬失效、报告证据表和更新历史以通用规则为准；本文件只补C浪特有歧义，不把通用方法局限于C。

## 所指结构

用于父级2/4等调整中，反弹后是否进入下行C浪的争议。上行C可镜像处理。先确认调整类型与被调整的父级段；三角形内部C不能套用锯齿/平台推动式C1–C5判据。

区分“候选B顶机械确认”“整个B段完成有依据”“仅B内部(a)结束”。B的一段上涨即使呈五浪，也不独立证明整个B完成；下跌仍可能是B内部(b)。

## C专项证据—结论

| 新增证据 | 我会采用的结论 | 仍需保留 |
|---|---|---|
| 仅触发上游既定的顶部机械反转门槛 | 反弹顶获机械确认，建立C候选 | B内部回调；不能直接定父级C |
| 结构支撑收盘失守，已观察到反抽失败及再破低 | 下行延续优先，C候选增强 | 趋势可先偏空；B身份未解决时C仍待证 |
| 上一级A/B解释合规，B完成有依据，初始推动下跌—修正反弹—续跌结构得到审计支持 | C已开启可列主计数，保留最强备选 | 任意跌—涨—跌不自动等于C1–C2–C3；父级结构仍需持续审计 |
| 收复破位支撑，但未触犯指定C起点约束 | 立即下行延续软降级 | 可能只是C2；C计数不自动失效 |
| 反弹越过指定C1起点 | 原C1–C2计数失效，重审B延长等备选 | 不静默移动C起点来保留计数 |

阈值、价位、端点和AND/OR条件由每次可得账本落实，不固定本次讨论的指数、日期或价格。无反抽的连续下跌可先判下行延续，但不得虚构C2/C3。

## 内部结构与父级完成

- 不必等C1–C5全部完成才列启动候选；“C启动主计数”“C子浪完成”“C整体结束”分别审计。
- 标准推动C按既有2浪起点、1/4重叠、3浪长度规则审计；未观察到C4/C5时不宣称最终长度检验通过。对角线需有独立合规依据，不能只为逃避重叠改名。
- 第一跌段即使有低一级五浪，也可能属于B内部(b)的组成部分；仍须解决上一级B身份。缺分钟顺序时保留待证。
- 跌破候选父级调整底可否定“该底已结束调整、启动新推动”的特定备选，不单独证明C，也不直接否定全部长期结构。

## 输出与兼容

在通用“浪段证据—结论与切换预判断”中填当前C命题，不另用C模板替代所有浪的评估。通用记录使用 `wave_transition_assessment`。

既有 `c_wave_assessment` 如需保留，沿用其C专项含义（截点、浪级、起点、趋势/C状态、证据、触发器、软/硬失效和历史）；不能装入非C浪，不能覆盖上游账本，也不能与通用记录矛盾。
