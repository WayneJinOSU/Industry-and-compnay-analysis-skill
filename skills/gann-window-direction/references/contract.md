Every observation node declares its actual `source`, `data_asof` or decision
timestamp, `available_at` and `data_quality`. The gate verifies timestamps rather
than trusting a narrative cutoff statement.

`scenario_weighting` is not part of the new contract. No code baseline weights
are generated or required.

## Level context

`level_context` is built after the current level registry has been attached. It
contains facts and settlement geometry, not directional scores:

```json
{
  "target_date": "YYYY-MM-DD",
  "data_asof": "YYYY-MM-DD",
  "available_at": "YYYY-MM-DDTHH:MM:SS+08:00",
  "source": "当前关键位登记、结构记忆与统一 ATR",
  "data_quality": "complete",
  "previous_close": 3600.0,
  "atr14": 50.0,
  "atr_method": "wilder_14",
  "decision_band": {
    "support_defense": 3550.0,
    "pressure_defense": 3650.0,
    "width_atr": 2.0,
    "range_quality": "wide"
  },
  "price_anchors": [
    {
      "anchor_id": "previous_close",
      "price": 3600.0,
      "source": "当前关键位登记",
      "role": "前收"
    }
  ],
  "close_bins": []
}
```

`range_quality` is `normal`, `wide` or `extreme_wide`; it describes geometry and
never changes scenario weights. `price_anchors` includes the previous close,
ATR-derived observation anchors, current support/pressure defenses, tail
threshold and registered levels. LLM path prices must match this registry.

## Close-settlement bins

Exactly four contiguous bins are generated by `level_context.py`:

```text
tail_extreme_down: bearish
downside_continuation: bearish
range_oscillation: neutral
upside_breakout: bullish
```

Each bin has `name`, `direction`, `lower`, `upper` and `close_condition`. Bins
use `[lower, upper)`, except that the final bin includes its upper bound. They
have no `weight`, no path probability and no top-level direction. The close-axis
convention remains `lower_inclusive_upper_exclusive`.

```json
    "upper": 3650.0,
    "ordered_steps": [
      {
        "action": "测试支撑",
        "level": 3550.0,

      },
      {
        "action": "观察压力拒绝",
        "level": 3650.0,

    "trigger_level": 3650.0,
    "close_lower": 3650.0,
    "close_upper": 3700.0,
    "invalidation": "重新收回压力下方"
  },
  "downside_switch": {
    "trigger": "支撑有效击穿且反抽不能收复",
    "trigger_level": 3550.0,
    "close_lower": 3500.0,
    "close_upper": 3550.0,
    "invalidation": "重新收复支撑"
  },
  "tail_risk": {
    "trigger": "尾部阈值失守并放大波动",
    "trigger_level": 3450.0,
    "close_lower": 3400.0,
    "close_upper": 3450.0,
    "invalidation": "快速收复尾部阈值"
  },
  "structure_path_divergence": "次日修复是否改变中期结构及其理由"
}
```

All numeric levels above are illustrative only; a real judgement must use prices
registered in the current `level_context`. A switch requires a trigger,
trigger level, switched close zone and invalidation. Tail risk is a conditional
risk path, not a claim that an extreme move must occur.

Close location values:

```text
center | upper_edge | lower_edge | below_support | above_pressure
```

The label must match the close-zone geometry against the current defenses:
`below_support` requires `close.upper <= support`; `above_pressure` requires
`close.lower >= pressure`; edge labels must contain their corresponding defense;
`center` must lie strictly between support and pressure.

Close character values:

```text
strong | weak | balanced
```

Bearish structure plus a strong close, or bullish structure plus a weak close,
requires a non-empty `structure_path_divergence`. The explanation must not
silently change structure.

## Critical evidence

```json
{
  "conditional_base_rates": [],
  "unmatched_rates_not_used": [],
  "critical_levels": [
    {"level": 3550.0, "role": "支撑"},
    {"level": 3650.0, "role": "压力"}
  ]
}
```

This block contains facts only. Do not copy `core_thesis`, `next_day_baseline`,
`structure_path_audit` or `direction_audit` into it; `llm_judgement` is the sole
source for those decisions and their reasons. A conditional base rate can be
marked `used_in_judgement` only when its state exactly matches. It is evidence,
not a weight formula.

## Forecast record

The forecast copies the validated judgement and current level context:

```text
metadata and ruleset_version
structural_bias
window_state
next_day_baseline
opening_zone / intraday_zone / close_zone / close_character
next_day_path
structure_invalidation
baseline_path_invalidation
execution_state / action_bias / abstain
close_axis / interval_convention / close_bins
level_context
execution_overlay
llm_judgement
judgement_source=llm
```

There is no `direction`, `confidence`, weighted `scenarios` or `targets` object.
Structure, baseline-path and action invalidation remain separate.

## Report and audit

The brief contains:

1. Metadata and decision card.
2. Core trading judgement and structure/path divergence.
3. Compact evidence and gap table.
4. Opening → intraday → close baseline, switches and tail risk.
5. Script-generated execution risk facts, followed by the LLM's complete action rationale.

The audit contains timestamps, upstream ledgers, full evidence, level ladder,
base-rate definitions and the four weight-free close-settlement bins. Review
attribution uses `data_gap`, `classification`, `judgement` and `rule_gap`.

## Settlement and versioning

New records use path settlement only. Do not calculate execution scores,
hypothetical action returns or numerical confidence. Keep the original judgement,
frozen forecast and realized market data. Legacy weighted records use a separate
legacy branch and remain frozen. Backfills never enter prospective accuracy.

Current ruleset: `2026-10-28.4`.
