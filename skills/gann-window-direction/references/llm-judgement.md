# 大模型综合研判契约

## 定位

代码负责点时数据、状态量、关键位记忆、基线权重和技术风险参考。大模型负责最终
综合研判，包括四情景权重、方向、执行状态、操作动作和完整理由。

代码基线不得被直接当作最终结论。大模型可以偏离基线，但必须引用点时证据并解释
偏离原因。

## 输入

大模型必须读取完整的输入包，至少包括：

- 江恩时间点与空间共振。
- 波浪父级与当前浪候选。
- 多日价格路径、成交额和宽度。
- 两融和领涨结构。
- 外围市场、黄金与早开亚洲市场。
- 关键位登记及破位/收复记忆。
- 代码基线权重与执行风险参考。
- 数据缺口及其对置信度的影响。

所有输入必须满足点时截点约束。大模型不得引用目标日开盘后数据。

## 输出

大模型必须输出一个结构化研判对象，至少包含：

```text
source=llm
target_date
decision_at
core_thesis
structural_bias
window_state
direction
scenarios
targets
execution_state
execution_action
risk_state
confidence
supporting_evidence
opposing_evidence
action_maintenance
action_invalidation
evidence_refs
horizon
next_review
```

`direction` 只能是看多、看空或震荡对应的机器值。最高权重情景的固定方向必须与
`direction` 一致。

四情景固定映射：

| 情景 | 方向 |
|---|---|
| 向下延续 | 看空 |
| 区间震荡 | 震荡 |
| 向上突破 | 看多 |
| 尾部极值（向下） | 看空 |

## 理由完整性

- 至少2条支持最终动作的独立理由。
- 至少1条最强反方证据。
- 至少1条动作维持条件。
- 至少1条动作解除条件，且只能包含推翻当前动作的证据。
- 至少1条可解析的证据路径引用，例如 `structure_memory.recent_path_pressure`。
- 明确适用期限和下一次复查时点。

## 代码校验

代码只校验以下内容，不替大模型重新决定方向：

- 点时字段是否可证明。
- 四情景是否连续、无重叠且合计100%。
- 情景方向是否满足固定映射。
- 顶层方向是否等于最高权重情景方向。
- forecast 是否原样复制大模型研判。
- 操作动作和风险状态是否在允许枚举内。
- 理由、反方证据、维持与解除条件是否完整。

低确信阈值：最高权重与次高权重差不足5个百分点时，标记低确信；不得在正文中把
微弱权重优势描述为明确方向优势。
